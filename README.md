# Active-Directory-Home-Lab

  <img src="https://files.catbox.moe/i8heqc.png" alt="Wireshark Network Analysis Lab Banner" width="100%">
</p>


A hands-on Windows Server and Active Directory homelab focused on building, managing, securing, and troubleshooting an enterprise-style Windows environment.

---

## Labs

| # | Lab | Description |
|---|---|---|
| **01** | [Active Directory Deployment](./01-active-directory-deployment/) | Built an Active Directory domain with OUs, users, and security groups. |
| **02** | [Group Policy Management](./02%20-%20Group%20Policy%20Management/) | Created and configured Group Policy Objects for centralized Windows management. |
| **03** | [Group Policy Deployment & Testing](./03-%20Group%20Policy%20Deployment%20%26%20Testing/) | Joined a Windows client to the domain and deployed, tested, and verified GPOs. |
| **04** | [File Services and Network Sharing](./04%20-%20File%20Services%20and%20Network%20Sharing/) | Configured Windows file sharing, mapped drives, GPO drive deployment, quotas, and file screening. |
| **05** | [Implementing Security Policies](./05%20-%20Implementing%20Security%20Policies/) | Implemented password, account lockout, user rights, and fine-grained password policies. |
| **06** | [Service Accounts and Single-Purpose Computers](./06%20-%20Service%20Accounts%20and%20Single-Purpose%20Computers/) | Created a service account and configured a Windows client as a restricted kiosk-style workstation. |
| **07** | [NTFS and Share Permissions](./07%20-%20NTFS%20and%20Share%20Permissions/) | Practiced NTFS and share permissions and how they control access to shared resources. |
| **08** | [Troubleshooting Active Directory](./08%20-%20Troubleshooting%20Active%20Directory/) | Practiced diagnosing and troubleshooting common Active Directory issues. |
